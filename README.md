# 旬食材まるわかり v0.10

野菜・果物・魚の旬の話題と、出典付きの卸売価格を確認する静的Webアプリです。公開先はGitHub Pages、更新はGitHub Actionsです。

## 2026年11月13日の実データ検証

- 青果58品目の価格取得。56品目で比較可能な過去3～5年の同月・同旬から参考平年比を計算（54品目は5年分、2品目は3年分）。2021～2022年の参考推計も、誤差を明示して使用します。
- 魚11品目は2021～2025年の同月・同週・同じ銘柄区分の5年平均で参考平年比を計算。
- 青果は最大12旬、魚は月をまたぐ8週の価格推移を取得。
- 69品目・14,160時点の長期価格を収録。食材詳細で「時系列」「年ごとに比較」を切り替えられます。
- 魚は2021～2025年の各52週と2026年の44週、計304資料を検証。2024年1～2月の画像PDFは同じ公式HTML版で補完しました。
- 青果は2023～2025年の各36旬と2026年の30旬、計138資料を検証。2021～2022年の直接CSV/PDFはHTTP 403ですが、e-Statの日別公式CSVから全72旬を数量加重平均で再集計しました。これは旬別公表値ではなく参考推計です。2023年10月の3旬・各53～54品目で公表値と照合し、最大差は0.6円/kgでした。取得1,118件は失敗0件。3年分そろわない品目は判定を保留します。

これは独自計算の参考平年比です。青果は主要卸売市場計の平均単価、魚は豊洲市場の特定銘柄の中値であり、統計条件が異なります。小売価格ではありません。

v0.10では公式の品目コードを使い、国産・輸入の同名果実を混ぜないようにしました。ぶどう・メロンは国産の「計」、キウイ・レモン・グレープフルーツ・パイナップルは輸入果実の系列です。詳細に統計上の品目を表示します。数量・価額・単価がそれぞれ丸められる区間を照合することで、少量取引のふき等も公表単価のまま収録します。直接取得できる過年度138資料を同じ条件で再解析しました。

## 更新とデータの保存

`.github/workflows/update.yml` が毎日10:23 JSTごろに価格を確認します。公的話題の収集は火・木・土と手動実行時です。時刻はGitHubの実行状況により前後します。

`data/market_history.json` に、取得・解析できた価格、対象期間、原表URL、魚の規格を蓄積します。比較用の過去資料を毎回取り直さず、同じ期の訂正は上書きして重複を防ぎます。直近グラフ（青果12旬・魚8週）に加え、過去5年と今年の長期グラフを表示します。

過年度資料は `scripts/backfill_history.py` で通常1回24件まで、2並列・420秒以内を目安に追加取得します。成功資料は1件ごとに安全に保存し、失敗資料は7日後以降に再試行します。各点の価格・対象期・出典を保持し、魚は銘柄区分が違う値を混ぜません。季節的な取引なし・欠測・未取得を補間しません。集計条件を確認できない別市場の価格を全国青果価格に代用しません。

保存は一時ファイルから置き換え、取得失敗や未確認の形式で既存の正常データを消さないようにしています。更新状態、取得件数、平年比件数、グラフ点数、最終確認時刻を公開データに記録します。

青果の古い一覧ページがなくても、同じ主要卸売市場計の公式CSV本体を取得・検証します。魚の旧HTML資料は宣言されたShift_JISを正しく解釈します。

### 取得制限のある過年度青果

`scripts/estat_history.py` はAPIキー不要のe-Stat公開ファイルだけを使います。全国集計の野菜・果実のペアを日付照合し、全日分を取得した旬だけを公開します。日別の産地行・都市別資料を全国集計に混ぜません。国内果実と輸入果実も同じコード条件で選びます。欠落ファイルがある旬は公開せず、`data/estat_daily.json` に成功分を保存して次回再開します。通常の自動更新では1回80資料・約360秒を上限に取得します。

日別の数量・単価は丸められているため、数量加重平均は旬別公式価格を完全には再現しません。各点・比較年の「日別再集計」表示と、各日CSVへの直接リンクを付けます。日別数量を公表値±0.5kg・単価を±0.5円として保守的な参考範囲を計算し、85%・115%の境界をまたぎ得る場合は色を付けません。

## 旬の話題とGemini

農林水産省の月次野菜見通しに加え、東京都中央卸売市場の水産・果実の週間市況から、明記された食材別の文章を収集します。月次予報、週次の市場実績、全国と各市場の条件を区別し、公表日が確認できない場合は推定しません。

Geminiは取得済みの公的原文だけを要約します。出典URLをAIに作らせず、有料の検索グラウンディングも使いません。モデルは `gemini-3.1-flash-lite`、生成は日本時間で1日最大6回です。同じ原文の再要約を避け、429応答時は残りのAIリクエストを停止します。原文にない数値や検出できた見通しの断定化を含む要約は採用せず、原文の抜粋に戻します。自動チェックは意味全体の検証を保証しないため、AI要約は独立検証前と表示します。

27品目の最新資料に、対象地域、対象期間、実績／見通しの区分、根拠の原文を付記しました。市場の入荷を全国の漁獲量・収穫量と混同しないよう注記しています。農林水産省の価格見通しにおける「平年並み」（90～110%）とアプリの判定基準（85～115%）も区別します。既存のAI要約6件は原文と再照合して維持し、今回の検証による追加AIリクエストは0回です。

水産研究・教育機構の公式索引から、太平洋の浮魚類、対馬暖流系の浮魚類、太平洋スルメイカ、日本海中部ブリの最新予報を自動収集します。発表日、対象期間、PDFの魚種・海域を照合し、公式の概要と海域別条件を表示します。期限切れの予報を現在の話題に再掲載せず、同じ食材の市場実績と別海域の予報を詳細画面で併記します。地域によって逆方向の見通しや、0歳魚と2歳以上魚の違いを落とさないようにしています。

農畜産業振興機構「野菜情報2026年11月号」から、情報の薄かったセロリ・カリフラワー・かぼちゃ・さつまいも・ごぼう・れんこん・ミニトマトの産地別情報を追加します。記事全文を転載せず、短い引用と出典付きの事実整理を掲載します。今回ChatGPTで準備した要約は当該号・根拠文の一致時だけ使い、Geminiの生成件数と分けて記録します。りんごは青森県の最新「ふじ」熟度調査を索引から取得します。サンマの中短期予報、サケの来遊速報、カツオの季節予測も、対象海域・時点・予測と実績を区別します。

APIキーはGitHub ActionsのSecret `GEMINI_API_KEY` にのみ登録します。公開コードには含めません。有料プランへの変更や請求先登録は行いません。Google側の無料枠の適用はアカウント設定によります。

## 画面

既存の白・緑のデザイン、検索、旬カレンダー、お気に入りを維持しています。食材名の横は色の丸のみで、85%未満は青、85～115%は緑、115%超は赤、比較不能は灰色です。

魚の1尾・1杯価格は公表サイズから換算した概算です。推移は各週のサイズを用い、重量が分からない週がある場合は円/kgを表示します。利用者が重さを入力した場合は全期間を同じ仮定で試算します。むき身のカキは1個価格に換算しません。グラフの各時点と平年比の各年から原表を開けます。

## 検証

```sh
pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_ui.cjs
python scripts/preflight.py
python scripts/verify_prices.py
SOURCES_ONLY=true python scripts/update_topics.py --live
python scripts/backfill_history.py --live --limit 24
python scripts/estat_history.py --live --limit 80
python scripts/verify_history.py
python scripts/verify_consistency.py
```

`public-ui.yml` は公開更新の成功後、実際の公開URLをChromiumで開き、PC幅1280px・スマートフォン幅390pxで要約・5年グラフ・日別原表リンク・表記ゆれ検索・横はみ出し・JavaScriptエラーを確認します。画面キャプチャと結果JSONはActionsの成果物として7日間保存します。11月13日の公開画面で両表示幅の操作確認に成功しました（実機Safariでの確認ではありません）。期限切れの予報を残すことを要求するテストにはしていません。

`validate.yml` は開発ブランチでテストと実際の公的資料の取得を実行します。検証時はGeminiを呼び出しません。本番への反映前に結果を確認します。
